# yl3800.github.io

Homepage of Yicong Li (李易聪), USTC. Plain HTML/CSS, no build step: GitHub Pages serves the files as they are.

- `index.html`: home page (biography, research, highlights, selected papers, news, join us, honors, service, experience)
- `publications.html`: full publication list, grouped by year
- `assets/site.css`: all styles; colours are defined at the top in `:root`
- `image/profile.jpg`: profile photo (square, at least 400×400)

To add news, copy one `<li class="news-item">` block in `index.html`.
To add a paper, copy one `<div class="pub">` block in `publications.html`.
